# Security policy

Please **do not** report security problems in public issues or on Discord.

## Report a vulnerability

Use GitHub's private reporting for this repository: **[Report a vulnerability](https://github.com/sensmos-network/sensmos-firmware/security/advisories/new)**. Only the maintainers can see it. English or Polish is fine.

Tell us what is affected (component and version), how to reproduce it and what an attacker could do.

## What happens next

- We confirm we received the report within **3 working days** and give a first assessment within **7 days**.
- Critical fixes go to the tester channel first, then reach everyone in waves; a public advisory follows once the fix is out.
- If a vulnerability is actively exploited, we notify the national CSIRT and ENISA within 24 hours, as the EU Cyber Resilience Act requires.

Full policy and scope: https://sensmos.com/docs/security/ · security.txt: https://sensmos.com/.well-known/security.txt

## Supported versions

Only the latest release (and the current beta on the tester channel) receives security fixes. Nodes and the app update themselves; please keep them on the latest version.
